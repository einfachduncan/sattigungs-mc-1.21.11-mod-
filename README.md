# Sättigung Minecraft Mod 1.21.11

Eine Fabric Minecraft Mod für Version 1.21.11, die es dir ermöglicht, die Farbsättigung des Spiels anzupassen.

## Features

- 🎨 **GUI-Screen** - Benutzerfreundliche Oberfläche zur Anpassung der Sättigung
- ⌨️ **Konfigurierbarer Hotkey** - Standard: `S` (änderbar in der Config)
- 🎚️ **Sättigung-Regler** - Slider zur Echtzeit-Anpassung
- 💾 **Automatische Speicherung** - Einstellungen werden gespeichert

## Installation

1. [Fabric Loader](https://fabricmc.net/) für 1.21.11 installieren
2. Diese Mod in den `mods` Ordner ziehen

## Verwendung

- Drücke **S** um die GUI zu öffnen/schließen
- Nutze den Slider um die Sättigung anzupassen
- Die Einstellungen werden automatisch gespeichert
